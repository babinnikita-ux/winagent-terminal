# Governance

WinAgent Terminal is maintained through transparent GitHub issues and pull
requests. Repository maintainers review changes for product fit, security,
compatibility and attribution before merging.

## Decisions

- Material architecture, security and compatibility choices are recorded in
  `docs/adr/`.
- Pull requests require a clear scope, testing notes and any manual steps.
- Upstream wmux history and copyright remain attributed to
  [amirlehmam/wmux](https://github.com/amirlehmam/wmux).

## Maintainer responsibilities

Maintainers keep the default branch protected by review and CI where GitHub
settings permit, coordinate security reports privately, and avoid presenting
upstream work as original WinAgent Terminal work.
