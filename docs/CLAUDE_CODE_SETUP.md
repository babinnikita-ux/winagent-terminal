# Claude Code through ProxyAPI

Install Claude Code according to its official instructions, set `PROXYAPI_KEY`
as described in [ProxyAPI setup](PROXYAPI_SETUP.md), then restart WinAgent
Terminal. Select **+ → Claude Code via ProxyAPI** in the target pane.

The spawned process receives only per-process environment variables; no global
Claude configuration is overwritten. Choose **Resume Claude Code** to open the
CLI's own resume workflow.
