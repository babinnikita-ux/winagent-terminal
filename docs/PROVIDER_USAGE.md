# Лимиты провайдеров

WinAgent показывает только подтверждённые данные. `ProviderUsageService` работает в main-процессе и передаёт renderer уже нормализованный снимок: токены, cookies, ключи, конфигурации и stdout CLI никогда не пересекают IPC-границу.

Claude принимает только очищенный payload status-line bridge. Для Codex
поддерживается очищенная структура `rateLimits` app-server, для Gemini —
структура `quotas`; парсеры отклоняют произвольный stdout и повреждённые данные.
CLI проходят capability check через `--version`. Пока нет подключённого
стабильного машиночитаемого источника, интерфейс честно показывает «Данные
недоступны», а не оценку. Обновление выполняется при запуске и не чаще 90
секунд; снимок старше пяти минут помечается как устаревший.
